# tin-lia
tin-lia is a linux in a app project made in C.

## notes
- this is for educational use
- please don't mess with the platform spesific libraries
- this is in early development
- there is no documentation

## building
to build, run 
```bash
make build # for linux binaries
make build PLATFORM=win # for windows binaries requires a mingw cross compiler!
```
## running
to run it, just launch the binary
